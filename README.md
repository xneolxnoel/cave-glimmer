# 洞窟微光 · Cave Glimmer

一个关于"光"的横版洞窟冒险网页游戏。你是一个提着火把的兜帽旅人，在越来越深的洞窟里前行——照亮、战斗、并抵达每一处发光的终点。

纯原生 HTML5 Canvas + JavaScript，无框架、无依赖、无构建步骤，双击即玩。

## 玩法与操作

| 按键 | 功能 |
|---|---|
| A / D 或 ← / → | 移动 |
| W / ↑ | 跳跃 |
| 空格 | 攻击（点按）/ 蓄气（长按） |
| Shift | 闪冲（短距离高速位移，期间受伤减半） |
| Q | 格挡（火焰盾，消耗格挡条，挡下攻击攒气） |
| E | 释放气焰（气 ≥75 喷火锥 / 气满 100 全屏喷火大招） |
| R | 重来 |

## 关卡

1. **微光** — 氛围走廊，熟悉移动与跳跃
2. **水岸** — 水面石台连跳；落水即火把熄灭
3. **暗影** — 暗影虫出现；四段连斩、气条与格挡登场
4. **沉水洞窟** — 水面与暗影交织；精英暗影（大体型、高血量）
5. **暗影王座** — Boss 战：暗影之王
6. **滴水回廊** — 压力石板机关；被钟乳石滴水浇中即熄灭

气条系统：砍中暗影 +25 气、格挡 +12、被击 +10、长按空格蓄气（上限 3/4、松手流失）。气 ≥75 可释放喷火锥，气满 100 可释放全屏喷火大招。

## 运行

无任何构建与依赖——直接双击 `index.html`，或在任意静态服务器上托管本目录。

## 开发

- `game.js` — 全部游戏逻辑（关卡数据驱动，`LEVEL1..LEVEL6`）
- `tools/build_fragment.py` — 生成会话内预览用的单文件副本（开发辅助，非必需）
